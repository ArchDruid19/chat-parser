# chat-parser
This program takes a livestream chat from YouTube in JSON format and converts it to human readable text. **The JSON file must have been aquired from yt-dlp, as other downloaders may use differant property names for the JSON**.

Very much a work in progress right now.

## Features
- Groups chat messages by their author
- Allows a list of json files to be parsed in one execution
